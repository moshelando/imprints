## Replacement workflow

1. Replace image assets **in place using the same filename** whenever possible. That updates every page using the asset without touching HTML.
2. Search the repository for the placeholder ID/site/item when changing text content.
3. Re-check mobile and desktop after replacing images because real photography may crop differently.
4. Verify every factual claim, credential, price, result, address, date, policy, and legal/security statement before production use.
