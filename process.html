Process / site plan sequence

Draw the site
in the right order.

Every project changes in detail, but the sequence stays disciplined: observe the existing ground, organize use and movement, resolve structure, then plant into it.

01 / Observe

Start with what cannot be argued with.

Light, grade, runoff, access, existing trees, utilities, views and the daily path through the site are recorded before a new line is drawn.

01

Site walk + base plan

Construction sequence

Built structure
04

Plant + establish

Planting follows the built grade, then gets edited through the first seasons as the site settles in.
