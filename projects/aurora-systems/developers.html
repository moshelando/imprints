Developer interface

Keep model choice behind a stable runtime contract.

Aurora gives applications one execution surface while preserving route, policy, trace, and evaluation metadata as first-class output.

01 / QUICKSTART

Initialize once.

Configure a runtime client at the application edge. Route configuration and policy remain outside request-handling code.

import { Aurora } from "@aurora/runtime";

const aurora = new Aurora({
  environment: "production"
});
from aurora_runtime import Aurora

aurora = Aurora(
    environment="production"
)
02 / RUN

Make the task explicit.

The route name identifies the workload. Policy and evaluation metadata travel with the request.

request.ts
const result = await aurora.run({
  route: "support.answer",
  input: { question, context },
  policy: { dataClass: "customer" },
  evaluate: ["groundedness"]
});

console.log(result.traceId);
console.log(result.route);
