# Mosaic Labs

Mosaic Labs is an independent web design and front-end portfolio built as a static GitHub Pages site.

The repository contains the Mosaic Labs studio site plus ten complete project websites, each with its own visual system, responsive layouts, navigation, interactions, and page architecture.

## Structure

- `/` — Mosaic Labs studio / portfolio
- `/projects/aurora-systems/`
- `/projects/casa-rosso/`
- `/projects/apex-performance/`
- `/projects/kindred-wellness/`
- `/projects/maison-noire/`
- `/projects/pennywise-app/`
- `/projects/wild-north/`
- `/projects/northline-advisory/`
- `/projects/bennett-rowe-accounting/`
- `/projects/fieldstone-landscape/`

Static HTML, CSS, JavaScript, SVG, and JPEG assets. No build step is required.
